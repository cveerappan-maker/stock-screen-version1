# Ex-US Stock Screener

An investment theme screener for ex-US (international) markets. Ranks sectors and sub-sectors by performance across global regions.

## Features

- **Theme tab**: Investment themes ranked from best to worst performing
- **Date range picker**: Select 1D, 1W, 1M, 3M, 6M, YTD, 1Y or custom date ranges
- **Visualization**: Horizontal bar chart of theme returns with drill-down line charts
- **Filters**: Filter by sector and region
- **20 ex-US themes** spanning defense, luxury, semiconductors, banking, energy, pharma, and more

## Tech Stack

- React + Vite
- Tailwind CSS v4
- Recharts
- React Router

## Getting Started

```bash
npm install
npm run dev
```
